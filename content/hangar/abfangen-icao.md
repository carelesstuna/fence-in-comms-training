Fliegt ein Flugzeug unangemeldet in gesperrten Luftraum oder antwortet nicht mehr, schicken
Luftverteidigungen Abfangjäger hoch – in Europa als **QRA** (Quick Reaction Alert). Oft spricht der Pilot
im Verkehrsflugzeug keine gemeinsame Sprache mit dem Jägerpiloten. Deshalb hat die ICAO ein Verfahren
festgelegt, das ohne lange Sätze auskommt.

**Funk:** Gerufen wird auf **121.5** (VHF-Guard), notfalls auf **243.0** (UHF-Guard). Der Abgefangene
meldet sich mit „intercepted aircraft“ und stellt **Squawk 7700** ein. Wenn sonst nichts geht, gibt es
feste Wörter, jedes **zweimal** gesprochen:

| Abfangjäger | Bedeutung | Abgefangener | Bedeutung |
|---|---|---|---|
| CALL SIGN | Wie ist dein Rufzeichen? | CALL SIGN … | Mein Rufzeichen ist … |
| FOLLOW | Folge mir | WILCO | Verstanden, mache ich |
| DESCEND | Sinkflug zur Landung | CAN NOT | Kann ich nicht |
| YOU LAND | Lande auf diesem Platz | REPEAT | Bitte wiederholen |
| PROCEED | Du darfst weiterfliegen | AM LOST | Ich weiß nicht, wo ich bin |
| | | MAYDAY | Ich bin in Not |
| | | HIJACK | Ich werde entführt |
| | | LAND (Ort) | Ich möchte in … landen |
| | | DESCEND | Ich muss sinken |

Auffällig: Hier steht ausnahmsweise „repeat“, das der normale Flugfunk meidet – die Liste ist bewusst
einfach gehalten.

**Sichtzeichen:** Der Jäger setzt sich leicht über, vor und meist links neben das Flugzeug und wackelt
mit den Flügeln: „Du bist abgefangen, folge mir.“ Der Abgefangene wackelt zurück und folgt. Ein steiles
Abdrehen weg vom Flugzeug heißt: „Du darfst weiterfliegen.“ Fahrwerk raus und Überflug der Landebahn
heißt: „Lande hier.“ Widerspricht ein Funkspruch einer anderen Stelle den Zeichen des Jägers, folgt man
dem Jäger und fragt nach, bis alles geklärt ist.
